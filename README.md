## Installation

1. Obtain the latest build from the project download link.
2. Unpack the script into your FiveM server's `resources` directory.
3. Register the resource in the server configuration.
4. Start or restart the server, then inspect the updated urban content in-game.

A standard resource configuration entry can be written as:

```cfg
ensure urban-content-update
```

The exact resource directory name can differ between packages. When configuring the server, use the folder name included in the downloaded build.
